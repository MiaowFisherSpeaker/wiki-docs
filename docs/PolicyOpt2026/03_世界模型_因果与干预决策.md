# 03|世界模型、因果与干预决策

> **本篇为什么放在一起读**:这两条线都在回答同一个问题:**不能(或不想)在真实环境里反复试错时,如何预测动作的后果,并据此优化策略?** 前半部分(世界模型)靠"学一个模拟器";后半部分(因果与干预)靠"从历史数据识别因果效应"。
> **建议顺序**:先读 WMA(最容易)→ ECHO / RWML / Code2World(看"预测什么、怎么训")→ 因果部分先读 Causal Identification 的"结论层"(定理陈述),再读 OPE with Strategic Agents。
> **阅读深度**:ICML 2026 论文为**速读**(读了本地 PDF 的引言、贡献陈述与结论,描述后标〔速读〕;个别重点论文已全文精读,见各自小节);ICLR / NeurIPS 论文因 PDF 无法脚本下载,为**摘要级**(只依据官方摘要)。

## 0. 本篇三个核心概念(给初学者)

1. **世界模型** $P_\theta(s_{t+1}\mid s_t,a_t)$:学出来的"模拟器"。关键设计问题是**预测什么**:整个状态?只预测变化?代码?潜变量?
2. **因果阶梯**:L1 观察、L2 干预、L3 反事实。越往上越难从数据中拿到。
3. **可识别性**:有些因果量**无论数据多大都算不出来**;这时要么加假设,要么给**区间(部分识别)**,要么对最坏情形做优化(minimax)。

## 1. 世界模型 × LLM Agent(优先:WMA)

### 优先论文二:WMA 网页世界模型(ICLR 2025)
📄 [官方页面](https://proceedings.iclr.cc/paper_files/paper/2025/hash/a00548031e4647b13042c97c922fadf1-Abstract-Conference.html) · 本地 PDF:`papers/ICLR2025/Web_Agents_with_World_Models.pdf` · 〔ICLR 2025〕

**全名**:*Web Agents with World Models: Learning and Leveraging Environment Dynamics in Web Navigation*
**作者**:Hyungjoo Chae 等(Yonsei University)
**链接**:[arXiv 2410.13232](https://arxiv.org/abs/2410.13232) · [代码](https://github.com/kyle8581/WMA-Agents)

#### 一句话

**让网页 agent 在点击之前,先用一个学出来的世界模型"想象"每个候选动作的后果,再选最好的**。策略模型(GPT-4o 等)完全不用重新训练。

#### 关键观察

作者先测试 GPT-4o、Claude-3.5-Sonnet 等:它们**预测动作后的下一状态很差**(二分类任务平均只有 54.75%),但如果*把每个候选动作的下一状态展示给它们*,它们选动作却明显更好。结论:**缺的是"预测后果"的能力,不是"评估后果"的能力**。

#### 方法

网页导航被建模为 POMDP:观测 $o_t$ 是无障碍树(简化 DOM),动作如 CLICK / TYPE。

**世界模型的训练目标**不是预测整页 HTML(太长、重复),而是预测**"变化了什么"的自然语言描述**(transition-focused observation abstraction):

1. 用匈牙利算法(基于元素名称、角色、位置的代价矩阵)匹配 $o_t$ 与 $o_{t+1}$ 的元素,得到"更新 / 删除 / 新增"的差分;
2. 让 LLM 把差分改写成自由文本 $\tilde o_{t+1}$;
3. 对 Llama-3.1-8B-Instruct 做下一词预测微调:

$$\mathcal L_\phi=-\log p_\phi\big(\tilde o_{t+1}\mid o_t,a_t,I\big)$$

**推理时的策略优化**(策略冻结):

1. 采样 $k=20$ 个候选动作,保留频次最高的 3 个;
2. 用世界模型对每个候选想象结果 $\tilde o^{\,i}=\phi(o_t,a^i,I)$;
3. 用价值函数 $V(I,o_t,a,\tilde o)$ 打分,选最高者。价值函数是在 Mind2Web 上微调的 Llama-3.1-8B。

#### 主要结果

| 设定 | 基线 | WMA |
|---|---|---|
| WebArena,GPT-4o | CoT 13.1% | 16.6%(相对 +29.7%) |
| WebArena,GPT-4o-mini | CoT 9.4% | 13.5%(相对 +43.6%) |
| Mind2Web 跨任务成功率 | AWM 15.3% | 25.4% |

- 效率:对比用*真实下一状态*的树搜索 agent,WMA 每实例 140.3 秒 vs 748.3 秒(快 5.3 倍),API 成本 $0.4 vs $2.7(便宜 6.8 倍)。
- 消融(GPT-4o-mini,200 个 WebArena 实例):完整 22.0%;去掉世界模型训练(直接提示)17.5%;**不做观测抽象、直接预测整树 14.5%**。这最能说明"预测什么"比"用多大模型"更重要。

#### 理论创新

这篇**偏工程**,理论上只有"用模型预测后果→选优"这个朴素的*基于模型的规划*思想,没有新的定理。真正的"理念创新"是:**世界模型的目标应该设计成"对决策有用的差分",而不是"完整重建"**。这与表示学习里"只保留与决策相关的信息"的想法同源。

#### 工程创新

- 观测抽象 + 差分描述,把"长 HTML 预测"变成"短文本预测",是性能的关键。
- 世界模型与策略解耦,可以接任意闭源 LLM。
- 作者承认的限制:预测误差随搜索深度累积;页面刷新后元素 ID 会变导致"想象"与"执行"对不上;购物类任务增益小;评估样本只有 100–200 实例。

#### 可带走认识

1. **想象比盲试便宜**:世界模型的最大价值常常是"省真实交互成本"。
2. **世界模型不需要预测一切**,只预测与决策有关的变化。
3. 这条思路在后面被推广到社会情境(见 `02` 的 Social World Model)和理论认证(见 `04` 的 World Models in Pieces)。

## 其他"给 LLM Agent 学世界模型"的论文(与 WMA 同一路线)

> 共同问题:Agent 在网页 / GUI / 终端里做动作,后果难预测、真实交互又贵。共同思路:**学一个"动作→后果"的模型,在想象里试错**。区别在于预测的**对象**(整页?差分?代码?潜变量?)和**训练信号**(监督?自监督?强化?)。

### WebWorld(ICML 2026)
📄 [官方页面](https://proceedings.mlr.press/v306/xiao26o.html) · 本地 PDF:`papers/ICML2026/WebWorld_A_Large_Scale_World_Model_for_Web_Agent_Training.pdf` · 〔ICML 2026〕
- **想法**:把世界模型做成**开放网页的"模拟器"**,用 100 万+ 条真实网页交互训练,支持 30+ 步的长程模拟,用来生产 Web Agent 的训练轨迹(摘要)。
- **类型**:工程为主(数据管线与规模)。
- **带走**:WMA 是"推理时想象",WebWorld 是"把想象变成训练数据工厂",二者是**同一思想的两种用法**。

## 因果与干预决策:与"策略优化"最紧的理论论文

> 这一组在问:**只有历史数据、不能随便做实验时,如何评估和学习策略?** 关键词:可识别性、部分识别、双重稳健、最坏情形。


## 2. 因果与干预决策(优先论文集中在这里)

### Causal Identification from Counterfactual Data: Completeness and Bounding Results(ICML 2026)
📄 [官方页面](https://proceedings.mlr.press/v306/raghavan26a.html) · 本地 PDF:`papers/ICML2026/Causal_Identification_from_Counterfactual_Data_Completeness.pdf` · 〔ICML 2026〕
**深度:全文读完(正文 §1–§3 与 §4–§5 的定理陈述;证明在技术报告 R-144 中,未核对)。** 作者 Raghavan、Bareinboim(哥伦比亚大学因果 AI 实验室)。

#### 背景:Pearl 因果阶梯与"数据能到哪一层"
- L1 观察 $P(Y|X)$;L2 干预 $P(Y_x)$;L3 反事实 $P(Y_x\mid X=x')$("若换成 $x$ 色的车,而原来是 $x'$,会不会被罚单")。**高层问题无法只靠低层数据回答,需要因果假设(因果图)。**
- 此前的**识别算法**:IDC*(Shpitser & Pearl 2008)对"已知全部 L2 数据"完备;CTFID(Correa 等 2021)对"L2 数据的子集"完备;PID(Zhang 等 2022)对不可识别量做**部分识别**。**共同前提**:输入数据只到 L1/L2,因为人们**认为 L3 数据不可能获得**。
- **新事实**(Raghavan & Bareinboim 2025):存在一类**反事实可实现(realizable)**的分布,可通过**反事实随机化**(ctf-rand)在实验里直接采样。ctf-rand$(X\to C)$:给 $X$ 的某些子节点 $C$ 看到一个**随机赋予的值**,但**既不覆盖该个体自然的 $X$,也不影响其他子节点**。

**例(交通摄像头)**:$X$=车色、$Z$=车速、$Y$=是否罚单,$X\to Z$、$X\to Y$、$Z\leftrightarrow Y$(未观测的路障)。**自然直接效应** NDE $=P(Y_{xZ_{x'}}=1)-P(Y_{x'}=1)$ 含嵌套反事实,因混杂**无法由 L2 数据识别**。但审计员可**随机改写视频里的 RGB 值**,使罚单模型"看到"车色 $x$,同时不影响真实车色与车速(图 1c)。这样
$$P(Y_{xZ}=1\mid X=x')\ \overset{X=x'\Rightarrow Z=Z_{x'}}{=}\ P(Y_{xZ_{x'}}\mid X=x')\ \overset{d\text{-分离}}{=}\ P(Y_{xZ_{x'}})$$
NDE 变得**可识别**。由此提出问题:**有了某些 L3 数据后,还有哪些 L3 量变得可识别?可识别性与可实现性是什么关系?**

#### 主要结果
| 结果 | 内容 |
|---|---|
| **CTFIDU⁺ 算法(Thm 3.5)** | 输入任意一组 L3 数据(含可实现的反事实数据),输出一个反事实查询的**识别表达式**,若不可识别则返回 FAIL;**可靠且完备**。**包含**此前 IDC*、PSIDC、CTFID 为特例 |
| **Def 3.1–3.2、Lemma 3.3** | 引入 **ctf-森林 / ctf-hedge**;ctf-hedge 是**不可识别性**的图结构证书 |
| **Lemma 3.4** | IDENTIFY⁺ 的可靠性与完备性(针对每个变量至多出现一次、构成一个 c-组件的 ctf-因子) |
| **Thm 4.1(识别的极限)** | 对 PCH 的中间层(L2.25、L2.5 等)有:存在 L2 查询可由 L1 数据识别;L2.25 查询可由 L2 数据识别;L2.5 可由 L2.25 识别;**但纯 L3 查询无法由 L2.5 数据识别**,例如图 5 中 $P(y_x\mid z_{x'},x'')$ 即使有其他可实现的反事实数据也**根本不可识别** |
| **Cor 4.2(识别-可实现对偶)** | 一个量能被**非参数识别**,**当且仅当**原则上可以通过对**每条边**做 ctf-rand 的实验来**实现** |
| **Prop 5.1(单调性)** | 输入数据越多,紧部分识别界**不会变宽**:$\mathbb A'\supset\mathbb A\Rightarrow[l,r]^{\mathbb A'}\subseteq[l,r]^{\mathbb A}$ |
| **Lemma 5.2 + Prop 5.4** | 在"弓形图"($X\to Y$,$X\leftrightarrow Y$)上,NTE 等 L3 查询,只用 L1 数据时界是 $[0,1]$(完全无信息);给出利用反事实数据的**解析界**,**可证明比此前的结果更紧**;模拟(Ex. 2、3)显示额外数据能显著缩小贝叶斯 $(1-\beta)$ 可信区间 |

#### 如何理解"对偶"
**非参数识别的本质,是在模仿"实验能做什么"**:若你能在原则上做出对每条边的随机化,就能直接测到;否则,不论多少数据都无法识别。这给出了**数据收集能力的理论上限**——决定"值不值得再设计某种实验"。

#### 理论 vs 工程
**纯理论**,以因果图 + 离散变量为设定。工程意义只在于:**指导实验设计**(哪些量值得去采、哪些采了也没用)。局限:需要**已知因果图**;反事实随机化的物理可行性依赖具体场景(论文引用其前作的附录 E 讨论条件)。

#### 给初学者的带走
1. **"识别"是不依赖数据量的结构性问题**:不可识别的量,再多数据也不行。
2. **数据层级(L1/L2/L3)越高,能回答的问题越多;**但也有"极限":哪怕有一些 L3 数据,纯 L3 查询仍可能不可识别。
3. 当不可识别时,**部分识别 + 区间**(与 `03` 中 Minimax 论文的思路相同)是务实的出路。

### A Minimax Approach for Optimal Intervention Policy Learning with Two-Stage Outcomes(ICML 2026)
📄 [官方页面](https://proceedings.mlr.press/v306/li26ef.html) · 本地 PDF:`papers/ICML2026/A_Minimax_Approach_for_Optimal_Intervention_Policy_Learning.pdf` · 〔ICML 2026〕
**深度:全文读完(正文方法、定理、实验;附录证明未逐条核对)。** 作者来自中国人民大学统计学院。

#### 问题
干预(优惠券、补习班、提醒)要发给谁?个体对干预有**两阶段**反应:$I$=是否**参与**(领券 / 报名),$Y$=是否**完成目标行为**(购买 / 成绩提升)。参与与完成的反事实组合决定了干预回报,但**同一个人不可能同时被观察到有干预与无干预**。

#### 主分层(principal strata)
假设干预前无人参与($I(0)=0$)且单调($Y(1)\ge Y(0)$),个体落入 6 类,回报 $r_1,\dots,r_6$:

| 层 | $(I(0),I(1),Y(0),Y(1))$ | 含义(电商例) |
|---|---|---|
| $l_1$ | 0,0,0,0 | 不领券-从不买 |
| $l_2$ | 0,0,0,1 | **不领券-被激励才买**(收到优惠就买,但不用领;例中回报最高,"B 类") |
| $l_3$ | 0,0,1,1 | 不领券-总会买 |
| $l_4$ | 0,1,0,0 | 领券-从不买 |
| $l_5$ | 0,1,0,1 | 领券-被激励才买("A 类") |
| $l_6$ | 0,1,1,1 | 领券-总会买(发券纯亏,"C 类") |

策略 $\pi:\mathcal X\to\{0,1\}$ 的价值:

$$V(\pi)=\mathbb E\Big[\sum_{j=1}^{6}e_j(X)\,\pi(X)\,\{u(1;l_j)-u(0;l_j)\}\Big]+\text{常数}$$

其中**主分层得分** $e_j(x)=P(L=l_j\mid x)$ **不可识别**——数据里观察不到谁属于哪一层。

#### 核心理论想法:部分识别 + 最坏情形
- **Lemma 4.1(尖锐界)**:对 $e_2(x)$,
$$L(x)=\max\{0,\mu_{01|1}(x)-\mu_{1|0}(x)\},\quad U(x)=\min\{\mu_{01|1}(x),\ \mu_{1|1}(x)-\mu_{1|0}(x)\}$$
其中 $\mu_{ab|c}(x)=P(I=a,Y=b\mid T=c,x)$ 都是**可从数据估计**的条件概率。
- **最坏情形价值损失**:$R_{\sup}(\pi,\psi)=\max_{e_2\in[L,U]}R_{e_2}(\pi,\psi)$,其中 $\psi$ 是比较对象,取三种:**从不干预** $\pi_0$、**全部干预** $\pi_1$、**神谕** $\pi_o$。极小化极大策略 $\pi^*_\psi=\arg\min_\pi R_{\sup}(\pi,\psi)$ 满足预算 $\mathbb E[\pi]\le\epsilon$。
- **Theorem 4.2 / Prop. 4.3**:$R_{\sup}(\pi,\psi)=C_\psi-\mathbb E[\pi(X)\{s\cdot b_\psi(X)+c(X)\}]$,最优策略是**阈值规则** $\pi^*(x)=\mathbb 1\{s\,b_\psi(x)+c(x)>\gamma(\epsilon;\psi)\}$,阈值随预算单调递减。
- **三个估计器**:P-OR(回归)、P-IPS(逆倾向加权)、P-DR(双重稳健)。
- **Theorem 5.1 / 5.2(超额最坏情形损失上界)**:由四项决定——策略类的 Rademacher 复杂度 $\mathcal R_n(\Pi)$、倾向得分误差、回归误差、分类器 $\hat\delta_l,\hat\delta_u$ 的遗憾;用 SVM 类时总体可达 $O(1/\sqrt n)$。

#### 实验
MovieLens-1M、Jester(以及附录 KuaiRec)上构造"邀请参加路演→参加→是否高评分"的反事实场景,按预测分数给用户标注主分层(NCF 预训练)。相比**朴素预测法**与**uplift 建模(OR / IPS / DR)**,回报提升:ML-1M 上 P-OR 22.2%、P-IPS 30.8%、P-DR **44.3%**;Jester 上 43.6% / 57.1% / 31.6%。(注意:分层标注是**半合成构造**,不是真实反事实。)

#### 理论 vs 工程
- **理论创新(主要)**:用**部分识别**把"不可识别"变成可优化的**区间**,再用 minimax 把区间变成保守策略;不需要此前文献中的**排他性假设**(假定某些层不存在)。
- **工程**:很轻——三个标准估计器 + 标准监督学习器求策略。
- **局限**:反事实标注是模拟的;minimax 相对于三个基准而非一个,实务中怎么选基准没有定论;单调性假设需要领域知识。

#### 给初学者的带走
**"无法识别"≠"无法决策"**:当数据只能给出区间时,可以对区间内最坏情形做优化。这与社会情境里"对手类型不可知 → 对类型取最坏情形"(见 `09` 的 Bayesian Robust MARL)是同一个思想。

### GIFT:Target-Driven Policy Optimization for Sequential Counterfactual Outcome Control(ICML 2026)
📄 [官方页面](https://proceedings.mlr.press/v306/wang26ko.html) · 本地 PDF:`papers/ICML2026/Target_Driven_Policy_Optimization_for_Sequential_Counterfact.pdf` · 〔ICML 2026〕
**深度:全文读完(正文;附录证明未逐条核对)。** 作者来自中科大、南洋理工;代码 `github.com/wangxin0126/GIFT`。

#### 问题:序贯反事实目标达成(SCTA)
从**观测的纵向数据**(如病人历史:协变量 $X_t$、连续干预 $A_t\in[0,1]^d$、结果 $Y_t$)中,学一套干预,使系统最终到达目标 $Y_{\text{target}}$。此前做法是"先学反事实预测模型,再离线**规划**一条固定干预序列"(开环),缺点是**轨迹一偏离计划就失效**,且推理时优化昂贵。

#### 建模:目标条件 MDP
- 状态 $\Psi_t=(\bar H_t,Y_{\text{target}})$:完整历史 + 目标;动作 = 干预;奖励 = **稀疏步罚**
$$r_{t+k}=\begin{cases}0,&Y_{t+k+1}\in\mathcal T\ \text{且首次命中}\\-1,&\text{否则}\end{cases}$$
目标区域 $\mathcal T=\{y:\|y-Y_{\text{target}}\|\le\delta\}$。折扣累计回报越大 = 越快到达目标。

#### 三个难点与两个机制
难点:**混杂**(历史治疗由医生依病人情况决定)、**分布偏移**(离线数据覆盖不到学到的策略)、**奖励稀疏**(命中目标的样本很少)。

1. **事后经验回放(HER)**:把轨迹里**实际到达的未来结果**当作虚拟目标 $g'$ 重新标注,把"失败样本"变成"成功样本"。依赖 **Assumption 4.1(目标无关动力学)**:$P(S_{t+1},G_{t+1}\mid S_t,G_t,A_t)=P(S_{t+1}\mid S_t,A_t)\cdot\mathbb 1[g'=g]$,即给定当前状态与干预,目标本身不直接影响下一状态(如血糖对胰岛素的反应不取决于医生的长期目标)。
2. **奖励重缩放**:用被**裁剪**的重要性比 $\bar\rho=\operatorname{clip}\big(\pi_\theta(a\mid\psi)/\pi_b(a\mid\psi),\epsilon_1,\epsilon_2\big)$ 乘以即时奖励 $\tilde r=\bar\rho\,r$。直觉:策略比行为策略更偏好某动作时放大它的奖励,反之缩小,把 Bellman 目标"拉向"当前策略分布。**只做单步重加权,避免轨迹级重要性采样的方差爆炸。**

架构:LSTM 编码历史、MLP 编码目标、融合 MLP 得到状态;SAC(连续动作,sigmoid 压缩的高斯);另训练一个行为策略估计 $\pi_b$。

#### 理论
- **Prop 4.1(因果可识别)**:在目标无关动力学与标准因果假设(一致性、序贯可忽略性、正性)下,软 Bellman 评估算子是**可从观测分布识别**的——可由单步重要性加权表示(式 (6))。
- **Thm 4.2(压缩性)**:改造后的算子 $\tilde{\mathcal T}^\pi$ 在 $\|\cdot\|_\infty$ 下是 $\gamma$-压缩,**所以有唯一不动点**。
- **Thm 4.3(收敛与偏差界)**:
$$\|Q^{\pi_\theta}-\tilde Q^{\pi}\|_\infty\le\frac{1}{1-\gamma}\,\sup_{\psi,a}\big|r(\psi,a)\,(1-\bar\rho(\psi,a))\big|$$
即与真实软 Q 函数的差距由**裁剪引入的系统性偏差**决定——裁剪越松偏差越小但方差越大(**偏差-方差权衡**由 $[\epsilon_1,\epsilon_2]$ 控制)。作者坦承这是"启发式修改 + 有界偏差",而非保证最优。

#### 实验
- 数据:**肿瘤模拟器**(PK-PD 模型,混杂强度 $\kappa=2,3,4$)与**基于 MIMIC-III 的半合成环境**(2 维结果,连续干预,模拟器已知真实效应)。
- 基线:RMSN、CRN、CT、ACTIN、VCIP(前面都是"学反事实预测 + 规划")、SCRL(离线目标条件 RL)。
- 指标:终点结果与目标的 RMSE;各混杂强度与各规划长度 $\tau$ 下 GIFT 的 RMSE 最低;对**训练中没见过的干预规则**(以概率 $\eta$ 覆盖原分配)也能泛化。
- 作者声明:评测在**已知动力学的模拟器**里,**不是对真实病人**,真实临床使用需前瞻验证与医生监督。

#### 理论 vs 工程
- **理论创新**:把"序贯反事实目标达成"形式化为目标条件 MDP;证明**可识别性 + 压缩性 + 偏差界**。
- **工程创新**:HER 与裁剪重要性加权是**现成工具的组合**(HER 来自机器人 RL,裁剪来自 PPO / 离线 RL);贡献在于把它们放进**观测因果数据**并给出分析。
- **局限**:裁剪区间怎么选缺乏数据驱动方法;HER 依赖目标无关动力学假设;仅在模拟 / 半合成数据上评估。

#### 给初学者的带走
**离线、有混杂的数据 + 稀疏奖励**是医疗、政策等现实场景的常态。GIFT 展示了"HER 补稀疏、裁剪权重补分布偏移"的**两件套**。与 `07` 的 GRPO 裁剪(PPO-Clip)对照读:**同样是"裁剪重要性比",目的不同**——PPO 裁剪为了限制更新步长,GIFT 裁剪为了控制偏差-方差。

### GVALID:Active Policy Optimization for Individualized Dosing via Gradient Variance Minimization(ICML 2026)
📄 [官方页面](https://proceedings.mlr.press/v306/wan26l.html) · 本地 PDF:`papers/ICML2026/Active_Policy_Optimization_for_Individualized_Dosing_via_Gra.pdf` · 〔ICML 2026〕
**深度:全文读完(正文;附录证明未逐条核对)。** 作者来自中科大;代码 `github.com/ry-wan/GVALID`。

#### 问题
个体化**连续剂量**(0–1)策略,实验预算很紧,且**每个个体只能被试验一次**(one-shot)。分成多轮批次(cohort):每轮选一批 $(x,t)$ 试验→观察→更新模型与策略。已有主动学习做的是"**降低全局预测误差**";但策略优化不等于全局估计:**把预算花在明显次优的剂量区域上去"补全拟合"是浪费**。

#### 建模
$Y^t_x=f(x,t)+\varepsilon$,剂量 $t\in[0,1]$;策略 $\pi:\mathcal X\to\mathcal T$,价值 $V(\pi)=\mathbb E_X[f(X,\pi(X))]$,遗憾 $R(\hat\pi)=V(\pi^*)-V(\hat\pi)$。用**高斯过程**作代理模型,策略取后验均值最大化 $\hat t^*_D(x)=\arg\max_t\mu_D(x,t)$。

假设:**Assumption 4.1(平滑)**$-\partial_{tt}f\in[\mu,L]$(沿剂量方向严格凹、曲率有界,对应药理学里的"单峰最优生物剂量 OBD")。

#### 理论核心(这篇的亮点)
- **Lemma 4.1**:逐点遗憾二次依赖于剂量偏差,$R(x;t)\le\frac L2|t-t^*(x)|^2$。
- **Theorem 4.1(不确定性遗憾界)**:
$$R(D)\ \le\ C_g\cdot\mathbb E_X\Big[\operatorname{Var}\big(g(X,\hat t^*_D(X))\mid D\big)\Big],\qquad C_g=\tfrac{L}{2\mu^2},\ g=\partial_t f$$
**读法**:策略的贝叶斯遗憾被"**推荐剂量处的梯度后验方差**"所控制。直觉:判断一个候选剂量是不是最优,关键是确认**梯度是否为 0(驻点)**,而不是把整条曲线都估准。
- **Corollary 4.1**:最优剂量是**平台区间**(饱和型响应)时,把 $t^*$ 换成最优集 $\mathcal T^*(x)$,界依然成立。

#### 方法(GVALID)
1. 从池中抽 $m$ 个代表个体,取当前策略推荐剂量 $t_j$;
2. 用**对称有限差分**近似梯度 $\tilde g_j=\frac{f(x_j,t_j+\delta)-f(x_j,t_j-\delta)}{2\delta}$——由 GP 的线性-高斯封闭性,$\tilde g$ 服从高斯,协方差 $\Sigma_{\tilde g}=A\Sigma A^\top$;
3. 目标 $\tilde\Phi=\operatorname{tr}\Sigma_{\tilde g}$;
4. **Theorem 5.1(单次观测 Schur 约减)**:加入一个候选查询 $q$ 后迹的下降为
$$\Delta(q)=\frac{\|\operatorname{Cov}(\tilde g,y_q)\|_2^2}{\operatorname{Var}(y_q)}$$
有闭式,因此可对候选集**贪心**选批次(目标是次模型,贪心有保证 $1-1/e$ 一类的性质——论文引用 Nemhauser 1978;我没有核对论文是否明确陈述该保证),并用**秩一 Schur 补更新**高效刷新协方差。

#### 实验
- 数据:4 个合成集(HNL 光滑单峰 / CSC 尖峰 / SWV 多峰,违反假设 / STS 平台型)+ 半合成 News(500 维特征)。预算=训练池的 20%。
- 基线:主动学习(MaxVar、Soft Top-K)、批量上下文老虎机(TS、GP-UCB、EI、PLAS、CATS)、因果主动学习(ABC3、PG)、随机。
- 指标:策略次优性 $R=\mathbb E[f(x,t^*)-f(x,\hat t)]$。以 $N=350$ 为例,GVALID 在 HNL 上 0.12(次优者 MaxVar 0.18)、CSC 上 0.40(最优基线之一 0.50)、STS 上 0.17(与 ABC3 并列)。**SWV(违反假设)上 N=150 时并不占优(0.65 vs PLAS 0.60),但随样本增多反超**。

#### 理论 vs 工程
- **理论创新**:把"策略遗憾"与"**梯度**后验方差"联系起来;并给出可计算的 Schur 约减。
- **工程**:GP + 有限差分 + 贪心,实现简单。
- **局限**:依赖平滑与严格凹假设;GP 的 $O(n^3)$ 复杂度限制大规模;只在合成 / 半合成数据上评估。

#### 给初学者的带走
**"为决策而学",而不是"为拟合而学"**:不确定性只有在**影响决策**的地方才值得消除。与 `03` 里 WMA"只预测对决策有用的差分"和 `04` 的"最优臂识别"是同一类思想。

### Smooth Multi-Policy Causal Effect Estimation in Longitudinal Settings / PEQ-Net(ICML 2026)
📄 [官方页面](https://proceedings.mlr.press/v306/chen26df.html) · 本地 PDF:`papers/ICML2026/Smooth_Multi_Policy_Causal_Effect_Estimation_in_Longitudinal.pdf` · 〔ICML 2026〕
**深度:全文读完(正文 §1–§5 的设定、方法与实验设置;Thm 4.2 的证明与附录未逐条核对)。** 作者来自康奈尔(Weill Cornell),代码 `github.com/Wenxin-Elmon-Chen/PEQ`。

#### 问题:要**同时比较多个**动态治疗策略
纵向观测数据 $O=(L_1,A_1,\dots,L_\tau,A_\tau,Y)$,有"**治疗-混杂反馈环**"(时变混杂既影响后续治疗、又被先前治疗影响)。要评估并比较 $K$ 个反事实动态策略 $\{\pi^{(1)},\dots,\pi^{(K)}\}$,目标是条件平均潜在结果 CAPO $\psi^{(i)}=\mathbb E[Y(\pi^{(i)})\mid L_1]$ 及其差(CATE)。

**ICE G-computation(迭代条件期望,从后往前)**:
$$Q^{\text{ICE}}_{\tau+1}=Y,\qquad Q^{\text{ICE}}_t(A_t,H_t)=\mathbb E\big[Q^{\text{ICE}}_{t+1}(\pi_{t+1}(H_{t+1}),H_{t+1})\mid A_t,H_t\big],\quad \psi=\mathbb E[Q^{\text{ICE}}_1(\pi_1(H_1),H_1)]$$
相比 IPTW(权重连乘,长程方差爆炸)和前向 G-computation(要建协变量转移模型),ICE 更稳。**LTMLE** 在其上做靶向去偏,校正一阶偏差。

#### 本文的诊断:"各估各的"的范式缺了结构约束
$Q^{\text{ICE}}_t$ **只依赖于策略的未来尾部** $\pi_{t+1:\tau}$。所以两个从 $t+1$ 起完全相同的策略,理应得到同一个 $Q_t$。但现有方法(DeepACE、DeepLTMLE)对每个策略**独立训练**整套倾向与结果模型。
- LTMLE 误差展开:$\hat\psi_n-\psi_0=\underbrace{P_nD^*(P_0)-P_nD^*(\hat P_n)}_{\text{plug-in 偏差}}+\underbrace{(P_n-P_0)[D^*(\hat P_n)-D^*(P_0)]}_{\text{经验过程项}}+\underbrace{\mathrm{Rem}(\hat P_n,P_0)}_{\text{二阶余项}}$。LTMLE 消除第一项;**二阶余项要求 $\sum_t\|\hat\pi_t-\pi_t^*\|\|\hat Q_t-Q_t^*\|=o_p(n^{-1/2})$,随 $\tau$ 增大越来越苛刻**(误差沿 ICE 递归向后传播);CATE 是两个 CAPO 之差,余项还会叠加。
- **Lemma 3.1**:即便两个策略**完全相同**,各自随机初始化训练时二阶余项之差 $\mathrm{Rem}^{(i),(j)}\ne0$ 几乎必然——**缺少结构性抵消**,使 CATE 受"模型噪声"而非"策略差异"驱动。

#### 方法(PEQ-Net)
1. **Q 函数策略重参数化(式 5)**:$Q_t(A_t,H_t,\pi_{t+1:\tau})$,把策略尾部作为**显式输入**;**Lemma 4.1**:该重参数化保持目标估计量的识别性。
2. **RKHS 策略嵌入**:对每步 $t$,把策略 $\pi_t$ 作用到全部观测历史,得到经验分布 $\{(h_t^{\ell},\pi_t(h_t^{\ell}))\}$;用**核均值嵌入** $\mu_t=\frac1n\sum_\ell\kappa_t(\cdot,z_t^{\ell})$ 表示;策略间距离用 **MMD**:$\mathrm{MMD}^2(\pi_t^{(i)},\pi_t^{(j)})=\|\mu^{(i)}_t-\mu^{(j)}_t\|^2_{\mathcal F_t}$;再用**度量多维缩放(MDS)**(SMACOF 求解)得到低维向量 $\rho^{(k)}_t\in\mathbb R^d$,使 $\|\rho^{(i)}_t-\rho^{(j)}_t\|^2\approx D_t[i,j]$。
3. **架构**:沿用 DeepLTMLE 的**仅解码器 Transformer**,共享参数的 G-head(倾向)与 Q-head(结果);Q-head 条件于**策略尾部嵌入**。训练用 target network 生成 G-comp 目标,最后做 LTMLE 去偏。
4. **Thm 4.2**:这种设计对二阶余项施加**结构约束**,稳定有限样本方差(证明未核对)。

#### 实验
- 数据:基于 **MIMIC-III** 的**半合成**(DeepACE 的 DGP:10 个时变测量 + 合成治疗与结果;以及扩展 DGP:再加 5 个与治疗**相互影响**的合成协变量以加强反馈环),$N=1000$ 条轨迹,$\tau=15$;800 训练 / 200 验证。另有脓毒症患者**血管加压药**的真实案例研究。
- 基线:ICE G-comp(Super Learner)、LTMLE(Super Learner)、DeepACE、DeepLTMLE。
- 反事实策略:(a) 确定性治疗序列(绕过 MDS,直接把序列输入编码器);(b) 动态策略(只与 DeepLTMLE 比),两种相似度情形:仅早期不同、后期重合 / 每一步都不同(压力测试)。
- 结果:偏差与 RMSE 下降,**海报称 RMSE 降低 13–62%**,在**策略相近时**收益最大(这与"共享表示利用相似性"的理论一致)。

#### 理论 vs 工程
- **理论创新(主要)**:指出"分别估计"在二阶余项上缺乏结构抵消(Lemma 3.1);用**重参数化 + MMD 度量**让相近策略共享估计(Lemma 4.1、Thm 4.2)。
- **工程创新**:MMD→MDS 策略嵌入 + Transformer 骨架。
- **局限**:实验为半合成,样本量仅 1000 条轨迹;策略数 $K$ 增大时 $K\times K$ 距离矩阵的成本。

#### 给初学者的带走
**当要比较的对象之间有共同结构时,联合估计比各自估计更稳**——这与 `09` 里 MARL 的参数共享、与 `08` 里"所有步骤共享同一个策略网络"是同一类共享归纳偏置,区别是这里有**因果层面的理论依据**(二阶余项)。

### Off-Policy Evaluation with Strategic Agents via Local Disclosure(ICML 2026)
📄 [官方页面](https://proceedings.mlr.press/v306/vo26b.html) · 本地 PDF:`papers/ICML2026/Off_Policy_Evaluation_with_Strategic_Agents_via_Local_Disclo.pdf` · 〔ICML 2026〕
**深度:全文读完(正文 §1–§3 的设定、分解与定理陈述;§4 实验与附录证明未逐条核对)。** 作者来自 CISPA、LMU、南洋理工。

#### 问题
离策略评估(OPE)要用旧策略 $\pi_0$ 产生的数据去估新策略 $\pi$ 的价值。但**被决策的人会针对策略修改自己的特征**(为拿贷款而调整财务行为)——于是协变量分布**依赖于策略**($\pi$ 变了,面对的人群就变了),破坏 OPE 的"协变量外生"假设。策略分类 / 表现性预测文献承认这点,但通常假设**所有人成本函数相同且已知**,或需要重复交互。

#### 关键想法:局部披露(Local Information Disclosure, LID)
- **全局披露(GID)**:决策者公开策略性质,只看到调整**后**的特征 $x^s$。两个原始特征不同、成本不同的人可能调整到同一个 $x^s$——**无法区分**,所以也无法推断反事实策略下的响应(论文图 1a)。
- **局部披露(LID)**:决策者**先看到**个体原始特征 $x^b$,再给**个性化反馈**(后验解释),个体据此调整。这样就能观察到**调整前的特征**,弥补信息不对称。
- 作者强调 LID 是**交互设计选择**,不只是估计技巧:**怎样设计与对象的交互,会决定你能推断什么。**

#### 模型
- 个体:原始特征 $x^b\sim P_{X^b}$(离散),策略 $\pi:\mathcal X\to[0,1]$,初次处理 $T^b\sim\text{Bern}(\pi(x^b))$。若被拒($t^b=0$),收到一份**含 $k\ge2$ 条推荐的行动推荐式解释(ARex)** $e=\{(x_{r_j},\pi(x_{r_j}))\}_{j=1}^{k}$(类似算法追索),可修改特征后重申请。
- **个体响应**(选择模型):
$$x^s\in\arg\max_{x\in\{x^b\}\cup\mathcal X^r}\ \big\{\pi(x)-\alpha\,d(x,x^b)\big\}$$
成本 $c(x,x')=\alpha\,d(x,x')$,**原始成本 $d$ 全体共享且已知**,**个体成本敏感度 $\alpha$ 未知**,并设 $\ln\alpha\mid x^b\sim\mathcal N(\beta^\top\phi(x^b)+\beta_0,\sigma^2)$。
- 结果 $y=h(x^s,t^s,z)$,$z$ 是外生噪声;**无混杂**:$Z\perp T^s\mid X^s$。目标 $V(\pi)=\mathbb E_\pi[Y]$。

#### 价值分解(核心恒等式)
$$V(\pi)=\sum_{t^s,x^s,t^b,x^b}\underbrace{\mathbb E_\pi[Y\mid t^s,x^s]}_{①\ 结果}\ \underbrace{p_\pi(t^s\mid x^s,t^b,x^b)}_{②\ 处理}\ \underbrace{p_\pi(x^s\mid t^b,x^b)}_{③\ 策略性响应}\ \underbrace{p_\pi(t^b,x^b)}_{④\ 初始}$$
**只有 ③ 是"策略性"的**,它由上面的选择模型决定,需要估计 $\theta=(\beta,\beta_0,\sigma)$。

#### 理论
- **Lemma 2.2**:在解释规则中**相邻推荐的距离互异**时,个体的效用最大化者**唯一**(概率 1),从而可写出响应概率。
- **Theorem 2.6**:在假设 2.3–2.5(识别性等)下,成本模型参数估计一致 $\hat\theta_n\xrightarrow{p}\theta^*$。
- **Theorem 3.2(策略稳健双重稳健估计器 $\hat V_{\text{SDR}}$ 的一致性)**:假设响应估计 $\hat p_\pi(t^s,x^s,t^b,x^b)$ 对任意 $\pi$ 一致、辅助分量独立估计且样本分开——则**结果模型 $\hat\mu(x^s,t^s)$ 一致,或重叠假设成立,二者有其一,$\hat V_{\text{SDR}}$ 就一致**。

#### 实验
合成数据与**德国信用数据**上验证估计精度(我只读到摘要与引言陈述)。

#### 理论 vs 工程
- **理论创新**:把博弈论中的"对象响应"与 OPE 的双重稳健估计结合,明确**披露机制 → 可识别性**的联系;分布假设(条件对数正态)换来一致性。
- **工程**:估计器本身是标准组件。
- **局限**:**一次性(one-shot)**、离散协变量、选择模型假设强(个体只在被推荐的有限选项中选择)、对数正态是**建模假设**而非可验证事实。

#### 给初学者的带走
1. **"对象会反应"有两种对策**:在线适应(如 `02` 的 ALSO)与**机制设计**(本文,通过披露设计让响应可观测)。
2. **双重稳健"二选一"**:结果模型对 **或** 倾向/重叠对,估计就是一致的——这是因果与 OPE 里最常用的稳健性保障。
