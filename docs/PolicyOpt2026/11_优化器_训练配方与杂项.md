# 11|优化器、训练配方、系统与其他杂项

> **本篇为什么放在一起读**:这里是"不属于前面主题、但与**策略优化的工程实践**相关"的论文:优化器怎么选、SFT 冷启动多久、温度怎么调、RL 的算力缩放规律、量化与异步训练;以及若干应用与跨学科的论文。**初学者可以只读 §1**,它们告诉你"这些训练里到底哪些旋钮重要"。
> **阅读深度**:ICML 2026 论文为**速读**(读了本地 PDF 的引言、贡献陈述与结论,描述后标〔速读〕;个别重点论文已全文精读,见各自小节);ICLR / NeurIPS 论文因 PDF 无法脚本下载,为**摘要级**(只依据官方摘要)。
