### 软硬件配置

**ALSO**(论文声明:单张 NVIDIA A800 80GB;LLM 推理走 OpenRouter API)

| | 最低 | 推荐 |
|---|---|---|
| 硬件 | 无本地 GPU:全部 LLM 调用走 API;嵌入模型也可换成 API | 1×24GB 以上显存(笔者估算,用于本地跑 Qwen3-Embedding-8B,bf16 约需 16GB 权重) |
| 软件 | Python 3.10+、PyTorch、Sotopia 环境(论文在其上扩展) | 同左 + OpenRouter / DeepSeek-V3.2 / GPT-4o 的 API Key |
| 关键超参(论文) | 策略数 $K=12$,最多 20 轮,$\lambda=0.9$,$\eta=10$,2 层 MLP(Pre-LN,隐层 512,GELU),lr 1e-3,嵌入 4096 维 | |
| 成本提示 | 费用主要来自 LLM API 调用(对话 + 逐回合评审 + GPT-4o 终评) | |

**WMA**(论文声明:世界模型训练约 3 GPU 小时,2 轮,lr 1e-5,**8×RTX 4090**;推理用 vLLM;基座 Llama-3.1-8B-Instruct)

| | 最低 | 推荐 |
|---|---|---|
| 硬件 | 只复现推理:1 张 24GB 显卡(笔者估算,Llama-3.1-8B 半精度) | 复现训练:8×24GB(与论文一致) |
| 软件 | Python、vLLM、OpenAI API(GPT-4o / GPT-4o-mini 作为策略)、WebArena 与 Mind2Web 评测环境 | 同左 |
| 注意 | WebArena 需要自行部署网站环境,配置较重(笔者经验,请参照其官方说明) | |

**Social World Model**(论文:Qwen3 0.6B / 4B / 8B 为世界模型和先验归因器;冻结后验用 Qwen3-32B 或 Qwen3.5-397B-A17B)

| | 最低 | 推荐 |
|---|---|---|
| 硬件 | 只推理:1×16–24GB 显存(笔者估算,Qwen3-8B) | 训练:1–4×40/80GB;后验归因若用 397B 级模型,需要 API 或多卡集群(笔者估算) |
| 软件 | PyTorch、HuggingFace Transformers、SWM-Bench 数据集 | 同左 + 推理服务(如 vLLM) |

**OmniSapiens / HARPO**(论文:基座 Qwen2.5-Omni-7B,用 VERL 实现 RL;**论文正文未写 GPU 型号**)

| | 最低 | 推荐 |
|---|---|---|
| 硬件 | 仅推理已发布模型:1×24GB(笔者估算) | RL 训练 7B 多模态:8×80GB 量级(笔者估算,GRPO 要同时跑生成与训练) |
| 软件 | VERL(volcengine/verl)、PyTorch、Qwen2.5-Omni、all-MiniLM-L6-v2 | 同左 |

**TRIRL**(论文:基线在 RTX 3090 上训练;LSIQ 因回放池大改用 RTX PRO 6000 Blackwell;环境用 MuJoCo XLA 并行)

| | 最低 | 推荐 |
|---|---|---|
| 硬件 | 1×RTX 3090(24GB)(论文) | 大回放池任务用 48GB+ 显存(论文) |
| 软件 | JAX、MuJoCo / MJX、Gymnasium;Unitree G1/Go2 任务需对应模型 | 同左 |

**PEQ-Net / CoPT-AIL / GIFT / GVALID**:论文中没有找到明确的硬件说明。PEQ-Net 的实验是半合成数据、每个设定重复 20 个随机种子。我的估计是**单张消费级 GPU 或 CPU 即可**,但这只是笔者估算,请以仓库说明为准。
