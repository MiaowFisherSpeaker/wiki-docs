## 0. 给初学者:怎么读一篇"遗憾界"论文

三个问题就够:

1. **衡量什么?** 遗憾 $\text{Regret}(K)=\sum_{k=1}^{K}\big(V^*-V^{\pi_k}\big)$:学习过程中累计比最优策略差多少($K$ 为回合数)。
2. **上界与下界各是什么?** 上界:算法保证不超过 $\tilde O(\cdot)$;下界:任何算法都至少要 $\Omega(\cdot)$。**两者匹配 = 最优(minimax optimal)**。
3. **假设是什么?** 表格 MDP?线性 MDP?奖励是随机还是对抗?假设越强,结论越"好看"但越不通用。

经典例子:对抗老虎机的 EXP3 遗憾为 $O(\sqrt{KT\log K})$,依赖**重要性加权**的无偏估计。*ALSO* 没有走这条路(见 `02`),所以不继承这个界。

## 1. 优先论文:观测受限与世界模型的可认证性

### Minimax Optimal Strategy for Delayed Observations in Online RL(ICML 2026,口头报告)
📄 [官方页面](https://proceedings.mlr.press/v306/lee26o.html) · 本地 PDF:`papers/ICML2026/Minimax_Optimal_Strategy_for_Delayed_Observations_in_Online.pdf` · 〔ICML 2026〕
**深度:全文读完(正文 §1–§5 的设定、算法与主定理;下界证明与附录未逐条核对)。** 作者 Harin Lee、Kevin Jamieson(华盛顿大学)。

#### 问题
智能体在执行动作后,**要延迟若干步才能看到状态**(传感器处理、传输、广告投放时看不到用户内在倾向)。于是必须**提前规划一串动作**——可能的动作序列数随延迟**指数增长**,所以"小延迟"似乎就会让问题变得很难。此前 Chen et al.(2023)证明多项式样本复杂度可行,但界很松:$\tilde O(H^{3/2}D_{\max}^{5/2}\sqrt{SAK})$,下界只有 $\Omega(\sqrt{HD_{\max}SAK})$,**两者差 $\tilde O(HD_{\max}^2)$**;并且"延迟长度是否影响统计复杂度"并不清楚。

#### 设定(随机延迟 MDP,SDMDP)
有限状态 / 动作的情节式 MDP + 延迟分布 $P_{\text{delay}}$ + 延迟上界 $D_{\max}$。允许"到达间隔"为 $-1$(同一步一次揭示多个状态)。**最优策略的充分统计量**(Katsikopoulos & Engelbrecht, 2003):三个量——**最后观测到的状态 $s_{t_h}$、未解决的动作队列 $\mathbf a$、距上次揭示过了几步 $\widetilde\Delta$**。记**分支因子** $B$(每个 $(s,a)$ 可达的后继数上界,$B\le S$)。

#### 方法:两步
1. **构造等价的增广 MDP**(无延迟):增广状态 $(s_{t_h},\mathbf a,\widetilde\Delta,h)$,大小对 $D_{\max}$ 指数。作者引入**两类中间状态**(`tran`:已决定揭示;$-1$:揭示后判断是否还有更多),让算法与分析更清晰。
2. **在增广 MDP 上用 UCB(基于 MVP / UCBVI 的 Bernstein 型奖励加成)**。**关键洞察**:增广 MDP 里**大量转移概率是共享的**——比如从 `(s,a,tran)` 到 `(s',a_{2:},-1)` 的转移,给出的是原 MDP $P_{s,a}(s')$ 的信息,可用于估计所有 $a'$ 以 $a_1$ 开头的增广状态。所以**只需估计原始的 $P$ 与 $P_{\text{delay}}$**,而不是指数多的 $P_{\text{aug}}$,计数也只记原始 $(s,a)$ 的访问次数 $N^k(s,a)$。
   - 对数因子变为 $\ell^*(D,b)=\big(D\log A+\cdots\big)\wedge\big(b\log\cdots\big)$——即取"动作队列长度 $D$"与"分支因子 $b$"中的较小者。

#### 理论结果
| 结果 | 内容 |
|---|---|
| **Thm 1(延迟分布已知)** | 以概率 $\ge1-\delta$,遗憾 $\tilde O\big(H\sqrt{(D_{\max}\wedge B)SAK}\,\iota+HBSA\,\iota^2\big)$,$\iota=\log\frac{HSAK}{\delta}$ |
| **Thm 2(未知延迟分布)** | 额外加 $H\sqrt{\Delta_{\max}SAK\iota}$ 与 $H(B+\Delta_{\max})SA\iota^2$ 项 |
| **Thm 3(下界)** | $\tilde\Omega(H\sqrt{D_{\max}SAK})$,与上界**仅差对数** |
| **对比 Chen 等(2023)** | 改进因子 $H^{1/2}D_{\max}^2$:$H^{1/2}$ 来自**方差相关的奖励加成**,$D_{\max}^2$ 来自**新的分析** |

**三条读法**:
1. **最优性**:上下界匹配,说明 $\sqrt{D_{\max}}$ 依赖是**不可避免也是足够的**——不是指数。
2. **"延迟越短,问题越简单"**:作者称这是首次严格证明"延迟相对于 $H$ 更短会降低统计复杂度"的结果。
3. **$D_{\max}$ 可被 $B$ 替换**:当分支因子 $B$ 更小时,依赖 $D_{\max}\wedge B$。原因:$D_{\max}$ 依赖来自对指数多状态的并集界,而可以换成对"定义域大小为 $B$ 的所有有界函数"的并集界。**所以延迟变长造成的性能下降不是无限的。**

**更一般的抽象**:转移动态分解为"**已知部分 + 未知但有结构的部分**"的一类 MDP,延迟只是特例;对此给出一般结论,适用于任何符合该抽象的领域。

#### 理论 vs 工程
**纯理论**。注意:**统计**上最优,不等于**计算**上高效——增广状态空间对 $D_{\max}$ 指数,作者在 §7 讨论该计算瓶颈是"看来不可避免"的(未读到细节)。

#### 给初学者的带走
1. **"统计复杂度"与"计算复杂度"是两件事**:本文说的是**要多少数据**,而非**算多久**。
2. **利用共享结构避免指数爆炸**:增广空间虽大,但参数只有 $P$ 与 $P_{\text{delay}}$ 这么多——"**参数数量 ≠ 状态数量**"是理论里常用的洞见。
3. 与 `04` 里的 ATST(内生观测)对照:那里把动作承诺成序列;这里同样用动作队列,但延迟是外生的。

### Reinforcement Learning with Action-Triggered Observations(ICML 2026)
📄 [官方页面](https://proceedings.mlr.press/v306/ryabchenko26a.html) · 本地 PDF:`papers/ICML2026/Reinforcement_Learning_with_Action_Triggered_Observations.pdf` · 〔ICML 2026〕
**深度:全文读完(正文 §1–§4 的建模与定理;§5 UCB 算法、实验与附录证明只读到陈述)。** 作者 Ryabchenko、Mou(多伦多大学)。

#### 问题:观测本身是一个"动作的后果"
不是每一步都能看到完整状态。**每个动作 $a$ 有一个概率 $\beta(a)$ 触发一次"数据爆发(data-burst)"**,此时才揭示当前状态(并给出自上次爆发以来的累计奖励);否则什么都看不到。例:医生在"有创但准"的检查与"无创但信息少"的检查之间权衡;交易员在"买高频行情数据的成本"与"决策质量"之间权衡。这类问题一般属于 POMDP,而通用 POMDP 在计算与统计上都不可解。ATST-MDP 的关键结构是:**一旦观测发生,状态就被完全揭示**。

#### 形式化(ATST-MDP)
六元组 $(\mathcal S,\mathcal A,P,r,\gamma,\beta)$,其中 $\beta:\mathcal A\to[0,1]$。它**包含**两类已有设定:ACNO-MDP(观测须付费购买)与间歇反馈(传感器不可靠)。与"观测延迟"不同,这里的延迟是**内生的**(由 agent 自己的动作引起),而经典延迟是外生的。

#### 理论一:增广状态与 Bellman 最优性(Thm 3.1)
增广状态 $x=(s_1,a_1,\dots,a_n)\in\mathcal S\times\mathcal A^{<\mathbb N}$ = "最后观测到的状态 + 之后做的动作序列",它是控制的**充分统计量**(类似 POMDP 的信念)。增广状态的转移核是混合:
$$P_{\mathcal X}(\cdot\mid x,a)=\beta(a)\,b(\cdot\mid x\oplus a)+\bar\beta(a)\,\delta_{x\oplus a}$$
定理证明:Bellman 算子 $\mathcal TV(x)=\max_a\{\mathbb E_{s\sim b(\cdot|x)}r(s,a)+\gamma\beta(a)\mathbb E_{s'\sim b(\cdot|x\oplus a)}V(s')+\gamma\bar\beta(a)V(x\oplus a)\}$ 是 $\gamma$-压缩,故最优增广策略存在、$V^*$ 是唯一不动点。

#### 理论二:动作序列重述(避免指数爆炸的关键)
增广状态空间对动作历史分叉。但任何固定策略从某个观测状态 $s$ 出发**只走一条分支**——于是把问题改写为:**在每次数据爆发时,观测 $s$,然后承诺一个动作序列 $\mathbf a\in\mathcal A^{\mathbb N}$ 一直执行到下一次爆发**。动作序列价值
$$K^\pi(s,\mathbf a)=\mathbb E\Big[\sum_{h=1}^{T_{DB}}\gamma^{h-1}r(s_h,a_h)+\gamma^{T_{DB}}V^\pi(s_{T_{DB}+1})\Big]=R(s,\mathbf a)+PV^\pi(s,\mathbf a)$$
把"爆发前的折扣奖励 $R$"与"续值算子 $P$"拆开(Prop 3.2 把它与 $Q^\pi,V^\pi$ 联系起来)。**核心观察:观测把过程"重置"成可更新(renewal)结构,所以比一般 POMDP 容易得多。**

#### 理论三:线性 MDP 下的线性表示与样本复杂度(§4)
线性 MDP 假设下,构造动作序列特征映射 $\psi$,使 $K^\pi$ **关于 $\psi$ 线性**;提出数据驱动的特征估计并证明非渐近样本复杂度 $\tilde O\big(d^3\varepsilon^{-2}(1-\gamma)^{-2}\big)$。
- **ATST-LSVI-UCB(§5)**:乐观价值迭代,遗憾 $\tilde O\big(\sqrt{d^3K(1-\gamma)^{-3}}\big)$(给定 $\varepsilon$-可容许的特征估计),**与全观测线性 MDP 的最优速率一致**——说明"稀疏观测"在这一设定下**没有额外的统计代价**(在特征已知或可估计的前提下)。
- 作者在若干仿真环境上做了验证(观测频率与任务结构的相互作用),我没有逐项核对实验。

#### 理论 vs 工程
**纯理论**,主要贡献是**建模 + 可解结构的发现**。局限:线性 MDP 假设强,特征映射 $\psi$ 需要(估计到)$\varepsilon$ 精度。

#### 给初学者的带走
**把"何时去看"也当作决策的一部分**。与 `04` 的 Delayed Observations 对照:这里的延迟由动作引起(内生),那里由环境随机决定(外生)。与 `03` 的世界模型对照:世界模型也是在"看不到"时靠预测填补——这里的"动作序列承诺"是一种**不用学模型**的替代。

### World Models in Pieces:Structural Certification for General Agents(ICML 2026)
📄 [官方页面](https://proceedings.mlr.press/v306/lu26ao.html) · 本地 PDF:`papers/ICML2026/World_Models_in_Pieces_Structural_Certification_for_General.pdf` · 〔ICML 2026〕
**深度:全文读完(正文 §1–§3 的定义、命题与定理陈述;算法 2/3 的细节与附录证明未逐条核对)。** 作者来自港中大(深圳)。

#### 背景:从"通用 agent 必含世界模型"出发
Richens & Everitt(2024)、Richens 等(2025)证明:**若 agent 在一大类长程目标上全局接近最优,则其内部必含一个可恢复的世界模型**。本文指出这类**全局 / 统一保证**的前提在"大世界(big world)"里不现实:一个 agent 对某些转移很准、对另一些很糟,而成败往往取决于**少数决定性的瓶颈转移**(登录、选对商品变体、提交结账表单),其余转移错了也无关紧要。

> **问题**:当 agent 对世界的认识必然不完整时,我们能否针对**特定任务**对它做**结构化认证**?

#### 形式设定
- 环境:**受控马尔可夫过程**(无奖励的 MDP)$\mathcal M=\{S,A,P_{ss'}(a)\}$,状态动作有限,任意状态间可达。
- 目标:用 **LTL(线性时序逻辑)**表达序贯目标。原语 $\varphi:=\mathcal O([\{s,a\}\in g])$,时序算子 $\mathcal O\in\{\top,\bigcirc,\Diamond\}$(现在 / 下一步 / 终将)。有序目标序列 $\psi=\langle\varphi_1,\varphi_2,\dots\rangle$,**深度** $\operatorname{depth}(\psi)=n$(时间跨度);析取组合 $\psi=\bigvee_k\psi_k$;全体深度 $\le n$ 的目标集 $\Psi_n$。
- 目标条件 agent $\pi(a_t\mid h_t;\psi)$,**失败率 $\delta$**:
$$\mathbb P(\tau\models\psi\mid\pi,s_0)\ \ge\ (1-\delta)\max_{\pi'}\mathbb P(\tau\models\psi\mid\pi',s_0)$$

#### 三个定义(这篇的"语言")
- **Def 2.2($(s,a,s')$-专属目标集)**:目标 $\psi$ 的最优成功概率**只**取决于一个转移概率 $P_{ss'}(a)$,即 $\max_\pi\mathbb P(\tau\models\psi)=f_\psi(P_{ss'}(a))$——把"agent 的表现"与"环境其余部分"**解耦**。
- **Def 2.3($(\delta,n)$-有界专属目标集)**:在上述目标集中,agent 达到失败率 $\delta$ 的那些目标。
- 作者给出规模 $\ge n$ 的显式构造(附录 D)。

#### 主要定理
| 结果 | 内容 |
|---|---|
| **Prop 3.1(通用 agent 不存在)** | 任何**非最优**的确定性马尔可夫策略,对任意 $\delta\in(0,1)$,总存在足够深的复合目标 $\psi_{\text{fail}}$ 使其失败率超过 $\delta$。⇒ **统一最坏情形保证没有信息量**,必须转向**转移局部**分析 |
| **Thm 3.2(结构化认证)** | 对每个被认证的转移 $(s,a,s')$,agent 的行为**唯一确定**一个动力学估计 $\hat P_{ss'}(a)$,误差 $O(1/n)+O(\delta)$。存在**过滤算法**(算法 1–3)用深层组合目标挑出被认证的转移 |
| **Thm 3.3(基本极限)** | 在被认证集合**之外**,任何由 agent 行为构造的"自洽世界模型"都必然与真实动力学**有不可消除的偏差** |
| 紧性 | 小 $\delta$ 区间内该界**紧** |

**读法**:agent 的**行为**就像"探针"——对一批只涉及单个转移的深层目标,如果它的失败率低,那么我们可以**从它的行为反推**出这条转移的概率,误差随目标深度 $n$ 按 $1/n$ 衰减。这样就得到一块块"**被认证的世界碎片**"。

#### 理论 vs 工程
**纯理论**。贡献是:**把"世界模型存在"从全局命题变成转移局部命题**,并给出可操作的构造。局限:假设环境**完全可观测、agent 确定性**;LTL 目标集的显式构造在大状态空间中的可行性尚未经验验证(我没有读到实验部分)。

#### 给初学者的带走
**别问"这个 agent 懂不懂世界",而问"它懂哪几块、能不能用这几块完成这个任务"**。这与 `03` 里 WMA 的观察对照:LLM 世界模型的错误**集中在反事实想象**(42%)等少数模式——也就是说**真实系统的世界模型确实是"碎片化的"**,结构认证提供了一种理论语言。

## 5. 本篇小结

1. **理论论文的"可带走物"通常只有一个**:一个界(如 $H\sqrt{D_{\max}SAK}$)或一个等价式(如奖励塑形不变性)。读的时候先找它。
2. **对 ALSO 的启示**:要给"策略选择"以保证,需要把"受 LLM 评审噪声影响的、非平稳的奖励"形式化(如 dynamic regret、带漂移的 bandit);本篇的 *Correlation-Aware Contextual Bandits*(臂相关 + 代理奖励)与 ALSO 的"替代网络"思想最接近。
3. **理论与工程的关系**:*Best-of-Majority*、*Strategic Scaling* 说明——**即便面对 LLM 这样的"工程对象",也能有 minimax 最优的结论**。
