# 13|目标导向的动作序列决策:为了达到目标,该做什么、按什么顺序做

> **本篇为什么单独成篇**:`07` 的标题是"策略优化",但它研究的是**更新规则**——裁剪、信赖域、基线、熵,即"已经有了一个策略,怎么把梯度算稳"。它基本不回答本篇的问题:**给定一个目标,智能体该选哪个动作、哪串动作,怎么推理出来?** 这类论文原本按方法或场景散在 `02`、`03`、`04`、`06`、`08`、`09`、`10`、`11`。本篇从全部 407 篇中把它们**筛出来、按"动作是怎么被决定的"重新分组**。
> **这是交叉视图**:论文的归属(`00` 索引里的"文档"列)不变,本篇每行都标了**出处文档**与推荐等级,详细笔记仍在出处文档里。
> **筛选标准**:论文必须把下面某一件事当作**研究对象**:(1)目标进入策略的输入;(2)在执行前对候选动作或动作序列做预测、搜索或规划;(3)先定子目标或计划、再执行;(4)为获取信息而行动;(5)对手或队友也在选动作时的最优响应。**只改训练稳定性、不涉及动作如何被选出的论文不收**(例如 `07` 的绝大多数论文、`08` 中纯粹的 token 级信用分配)。

## 0. 给初学者:同一个问题的四种问法

本篇所有论文都在回答同一个问题:**已知当前状态 $s$ 和目标 $g$,选动作序列 $a_1,\dots,a_T$ 使目标达成**。区别在于"谁会对你的动作做出反应":

| 问法 | 谁在动 | 动作怎么被决定 | 本篇小节 |
|---|---|---|---|
| **规划 / 目标条件控制** | 只有你,环境不会"对着你"变 | 把目标写进策略 $\pi(a\mid s,g)$,或者先想象后果再挑 | §1、§2、§3 |
| **主动推理** | 你,但你看不全状态 | 有些动作的价值在于**换来信息**,而不是直接推进目标 | §4 |
| **博弈 / 策略性交互** | 你和一个**会适应的对手** | 先推断对手(信念),再对它做**最优响应** | §5 |
| **协作** | 你和**队友**同时选 | 联合动作要协调,个体贪心不等于团队最优 | §6 |
| **干预决策** | 你作用于一个**被观测的系统或人群** | 动作 = 干预,目标 = 把结果推到某个区域;对象可能策略性地改变自己 | §7 |

另有三条贯穿全篇的区分,读每篇论文时先定位它在哪一侧:

- **开环 vs 闭环**:开环是先算好一整串动作再执行,中途不改;闭环是每步根据新观测重新决定。GIFT(§1)的出发点正是"开环计划一偏离就失效"。
- **训练时学到 vs 推理时搜出来**:前者把"怎么达成目标"压进参数(目标条件 RL、分层 RL);后者参数不动,靠世界模型、对手模拟或搜索在推理时找动作(WMA、对手模拟、ALSO)。
- **平坦 vs 分层**:平坦策略每步只选一个原子动作;分层策略先选子目标或计划,再由下层执行。长时程、稀疏奖励时,分层几乎是标配。

## 1. 目标条件策略:把"要去哪"写进策略的输入

> 共同思想:策略不是 $\pi(a\mid s)$ 而是 $\pi(a\mid s,g)$。难点几乎总是**奖励稀疏**(只有到达目标才有信号),共同的解法是**事后重标注**——把实际到达的状态当作"本来的目标",把失败轨迹变成成功样本。

|---|---|---|
| [Target-Driven Policy Optimization for Sequential Counterfactual Outcome Control](https://proceedings.mlr.press/v306/wang26ko.html) 〔ICML〕 | **GIFT**:从观测纵向数据学**序贯干预**,把系统推到目标区域 $\|Y-Y_{\text{target}}\|\le\delta$;状态 = 历史 + 目标,奖励 = 稀疏步罚;**事后经验回放**解决稀疏、**裁剪的单步重要性比**重缩放奖励以应对混杂与分布偏移;证明算子是 $\gamma$-压缩、偏差由裁剪决定。核心转变:从"离线规划一条固定干预序列"(开环)到"目标条件闭环策略" 〔深读〕 | 理论 + 方法 · `03` ★ |

## 3. 分层:先定计划或子目标,再执行动作

> 共同思想:长时程任务里,平坦策略要在每一步推断"这一步离最终目标还有多远",信号太稀。分层把决策拆成两级:**高层选子目标 / 计划 / 策略,低层选原子动作**。各论文的差别在于:高层输出是什么(自然语言计划、里程碑、策略摘要、推理深度),以及两层怎么分配信用。

## 4. 为了知道而行动:主动推理与观测受限下的动作选择

> 共同思想:当状态看不全时,有些动作本身不推进目标,但能**换来信息**(提问、查询、观察)。好的策略要在"探信息"和"做事情"之间权衡。理论上这对应 POMDP 与信念状态;本节还收了两篇把"什么时候能看到状态"与动作序列直接挂钩的理论论文。

## 8. 没有收录、但容易混淆的论文

- **`07` 的 GRPO / PPO 改进**(BandPO、TRM、最优 token 基线等):回答"怎么更新策略",不回答"该选什么动作"。它们是本篇方法的**底层工具**,训练本篇任何一种策略时都可能用到。
- **`08` 中纯信用分配的论文**(SSVPO、PiCA、Graph-Based Credit Assignment 等):把终局奖励分摊到各步,有用,但不对"目标 / 计划 / 子目标"建模;其中显式引入里程碑或计划的(BEACON、HiPER、StraTA)已收入 §3。
- **推理时搜索做数学题**(Functional MCTS、RL of Thoughts、AlphaRouter):搜索对象是推理 token 或推理结构,不是环境中的动作;如果你的"动作"就是推理步骤,可以回 `07` 查阅。
- **`10` 中的多 LLM 系统训练**(Dr. MAS、Stronger-MAS、MARTI 等):关注系统稳定训练,而非对手或目标下的动作选择。

## 9. 本篇小结

1. **"目标 → 动作序列"有五种问法**(§0 的表):规划、主动推理、博弈、协作、干预。先判断你的问题属于哪一格,再去对应小节找方法。
2. **三个开关决定方法形态**:开环还是闭环、训练时学到还是推理时搜出来、平坦还是分层。
3. **贯穿全篇的共同工具**:目标进输入 + 事后重标注(§1)、世界模型预测变化(§2)、子目标切分信用(§3)、信念状态(§4、§5)、最优响应(§5)。
4. 如果你关心的场景是"**对手会变、又不想重训大模型**",主线是:对手模拟(§5.1)+ ALSO(§5.1)+ WMA 式的"先想象后行动"(§2)。如果是"**长程单体任务**",主线是:GIFT(§1)→ HiPER / StraTA(§3)→ 信息自锁(§4)。
